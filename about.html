Program & Capstone // Bangkit Academy
Google · GoTo · Traveloka

Mobile Development Cohort — Bangkit Academy Led by Google

Mengikuti program Bangkit Academy pada alur belajar Mobile Development yang diselenggarakan oleh Google, GoTo, dan Traveloka. Di sini aku mendalami pengembangan aplikasi Android Native menggunakan Kotlin dengan arsitektur MVVM, lifecycle awareness, dan persistensi lokal Room SQLite.

Baca selengkapnya

Kurikulum mendalam mencakup pengelolaan asynchronous data streams menggunakan Coroutines & Flow, integrasi RESTful API, serta standarisasi Git branching collaboration tingkat industri.

Puncak program diselesaikan melalui Capstone Project kolaboratif: memimpin pengembangan modul client mobile native yang terintegrasi langsung dengan model machine learning dan cloud backend server tim lintas disiplin ilmu.

Kotlin Native MVVM Architecture Room Persistence Cross-Cohort Capstone
Peran Akademik // Asisten Laboratorium
FTI · ITENAS Bandung

Laboratory Assistant — Dasar Pemrograman (Bahasa C)

Dipercaya sebagai asisten laboratorium untuk mengajar dan mendampingi praktikum Dasar Pemrograman menggunakan bahasa C di FTI ITENAS Bandung. Membimbing mahasiswa memahami fondasi logika pemrograman: penguasaan tipe data, perancangan fungsi (function), struktur perulangan (loop), logika percabangan (if-else), hingga mekanisme penyimpanan berkas sederhana (.txt).

Baca selengkapnya

Aktivitas asistensi mencakup penjelasan alur algoritma di hadapan kelas praktikum, mendampingi mahasiswa saat mengerjakan latihan pemrograman di meja lab, serta membantu penelusuran kesalahan sintaks maupun logika program.

Pengalaman mengajar ini memperkuat pemahaman mendalam mengenai alokasi memori, manajemen pointer, dan kebiasaan menulis kode yang bersih serta terstruktur sejak tingkat dasar.

Bahasa C Tipe Data & Function Loop & If-Else Penyimpanan File (.txt) Praktikum Laboratorium
Kompetisi // Desain & Media
UI/UX & Infografis

Eksplorasi Desain UI/UX & Media Infografis

Mengikuti ajang kompetisi tingkat mahasiswa untuk mengeksplorasi perancangan visual, yaitu desain antarmuka pengguna (UI/UX) pada 4C National Competition serta menjadi finalis lomba infografis nasional pada ajang Agrocompetition (IPB University).

Baca selengkapnya

Pada ajang 4C National Competition, kegiatan berfokus pada penyusunan desain UI/UX menggunakan Figma, mencakup pembuatan rancangan wireframe, pemilihan komponen visual, dan perakitan prototipe alur interaksi aplikasi.

Sedangkan pada Agrocompetition 2025 (diselenggarakan oleh HMA IPB University), karya infografis yang dirancang berfokus menjawab tantangan rendahnya minat generasi muda terhadap sektor pertanian melalui pendekatan Framework Ten-O:

  • Capital & Empowerment: Penguatan kesejahteraan ekonomi petani melalui skema asuransi pertanian serta kepastian pembelian hasil panen lewat kontrak di muka.
  • Confident: Merombak persepsi publik agar profesi petani dipandang modern, bergengsi, dan relevan dengan teknologi bagi generasi muda.
